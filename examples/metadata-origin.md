# Источник воспроизводимых примеров

Файлы `pypi/<имя>/json` содержат только необходимые поля метаданных,
в структуре используемой части JSON API. Это не полные ответы публичного PyPI.
Программа получает эти JSON стандартным urllib через локальный HTTP-сервер,
не используя pip для построения графа.

## Сохранённые метаданные установленного окружения

Поля извлечены настоящей командой `python -m pip inspect` 12 ноября 2026 года:

- python-dateutil 2.9.0.post0: `six >=1.5`.
- six 1.17.0: зависимостей нет.
- pytz 2026.4: зависимостей нет.
- Jinja2 3.1.6: `MarkupSafe>=2.0`, `Babel>=2.7 ; extra == "i18n"`.
- MarkupSafe 3.0.3: зависимостей нет.

Первые три примера включены в исходную работу; Jinja2 и MarkupSafe добавлены
в этап 5 при дополнении от 13 ноября. В остальных ветках эти изменения не применяются.

## Фиксированная Babel для дополнительного примера

Для Babel 2.9.1 взяты поля публичного API конкретной версии:
https://pypi.org/pypi/Babel/2.9.1/json

Её `requires_dist` содержит `pytz (>=2015.7)`.
Это публичные метаданные, а не установленный Babel и не результат подбора версий pip.
Версия зафиксирована для небольшого воспроизводимого графа;
требование Jinja2 `Babel>=2.7` допускает версию 2.9.1.
Снимок сохраняет все объявления выбранных версий, включая необязательную группу `i18n`.
Программа не вычисляет extras: эта особенность не менялась при добавлении версий.

При запросе публичного PyPI используются метаданные последних версий;
они могут отличаться от снимка. Версии отображаются только на этапе 5
и только у реальных пакетов, а не у букв тестового JSON.
