# Источник воспроизводимых примеров

Файлы `pypi/<имя>/json` содержат только необходимые поля метаданных трёх
реальных установленных пакетов. Поля извлечены командой `python -m pip inspect`
при проверке работы 12 ноября 2026 года; это не полные ответы публичного PyPI.
Структура `info` воспроизводит используемую часть JSON API PyPI.

- python-dateutil 2.9.0.post0: `six >=1.5`.
- six 1.17.0: зависимостей нет.
- pytz 2026.4: зависимостей нет.

Снимок нужен для повторяемой демонстрации через локальный HTTP-сервер.
В программе метаданные считываются стандартным `urllib`, а не через pip.
При запросе публичного PyPI используются метаданные последней версии:
они могут отличаться от снимка. Например, версия python-dateutil 4.0.0
на момент проверки объявляла `tzdata`, а не `six`.

Публичные источники для самостоятельной проверки:

- https://pypi.org/pypi/python-dateutil/json
- https://pypi.org/pypi/six/json
- https://pypi.org/pypi/pytz/json
- https://pip.pypa.io/en/stable/cli/pip_inspect/
