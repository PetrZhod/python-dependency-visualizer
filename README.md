# Анализ зависимостей Python-пакетов

Вторая практическая работа. Программа использует стандартную библиотеку Python.

## Ветки

- stage-1 — параметры CLI, проверки ошибок, вывод ключ-значение.
- stage-2 — получение прямых объявленных зависимостей через JSON API.
- stage-3 — рекурсивный DFS, транзитивный граф, фильтр, циклы, тестовый режим.
- stage-4 — зарезервирована, пока указывает на stage-3; этап 4 не реализован.
- stage-5 — зарезервирована, пока указывает на stage-3; этап 5 не реализован.

main содержит только этот обзор. Для запуска выбери нужную ветку stage-1..stage-3.
README каждой реализованной ветки описывает соответствующий этап.

Начальная настройка и получение зависимостей не используют менеджеры пакетов.
Данные берутся из JSON API. В граф включаются все объявленные зависимости:
условия окружения и extras не вычисляются, версии не разрешаются как в pip.

Проверки в ветке:

```text
python -m unittest discover -s tests -v
python tests/check_style.py
```

Порядок установки, D2, изображение и ASCII-дерево будут добавляться позднее.
