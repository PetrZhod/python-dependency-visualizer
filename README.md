# Анализ зависимостей Python-пакетов

Практическая работа № 2. Консольная программа для анализа зависимостей Python-пакетов.
Программа использует стандартную библиотеку Python. Установка сторонних библиотек не требуется.

## Выбор этапа

| Ветка | Содержание |
|---|---|
| `stage-1` | Параметры командной строки, проверка ошибок, вывод конфигурации |
| `stage-2` | Получение прямых зависимостей из JSON API репозитория |
| `stage-3` | Транзитивный граф, рекурсивный DFS, фильтр, циклы и тестовый репозиторий |
| `stage-4` | Пустая ветка |
| `stage-5` | Пустая ветка |

Ветка `main` содержит описание работы. Исходный код и инструкции соответствующего этапа
находятся в ветках `stage-1`, `stage-2` и `stage-3`.

Для запуска выберите нужную ветку на GitHub, скачайте её через **Code → Download ZIP**
и распакуйте архив. Откройте PowerShell в папке, содержащей `src` и `run.bat`.
Требуется Python 3.10 или новее. Команды ниже выполняются из корня выбранного этапа.

## Запуск первого этапа

Выберите ветку `stage-1` и выполните:

```powershell
python src/main.py --package requests --repository https://pypi.org/pypi
```

Программа выведет пять настроек в формате `ключ=значение`. Интернет для этого этапа не требуется.
Примеры корректных параметров: `scripts/demo.bat`; примеры ошибок: `scripts/errors.bat`.

## Запуск второго этапа

Выберите ветку `stage-2` и выполните:

```powershell
python src/main.py --package requests --repository https://pypi.org/pypi
```

Программа получит и выведет прямые зависимости пакета. Требуется доступ к интернету.
Сценарий `scripts/demo.bat` показывает запросы для трёх пакетов.

## Запуск третьего этапа

Выберите ветку `stage-3` и выполните:

```powershell
python src/main.py --package A --repository examples/diamond.json --test-repo
```

Программа выведет граф тестового репозитория. Интернет для этого примера не требуется.
Сценарий `scripts/demo.bat` демонстрирует разные графы, циклы и фильтрацию.

## Справка и проверки

В каждой из веток `stage-1`, `stage-2` и `stage-3` доступны команды:

```powershell
python src/main.py --help
python -m unittest discover -s tests -v
python tests/check_style.py
```

Для запуска в Windows также можно использовать `.\run.bat` с теми же параметрами.
В Linux/macOS используйте `python3` вместо `python` или `sh run.sh` с параметрами.

## Анализируемые данные

Метаданные пакетов загружаются через JSON API без вызова менеджеров пакетов.
Учитываются все объявления зависимостей, включая extras и условия окружения.
Маркеры окружения не вычисляются, ограничения версий не разрешаются.
Результат описывает объявленные зависимости и может отличаться от состава установки pip.
