# Этап 5. Визуализация графа зависимостей

Программа строит граф зависимостей Python-пакета рекурсивным DFS, печатает описание
на языке D2, сохраняет изображение SVG и открывает его стандартным браузером.
По флагу `--ascii-tree` дополнительно выводится ASCII-дерево.
Зависимости получаются только стандартными библиотеками Python.

## Требования

Python 3.10 или новее и браузер для просмотра SVG. Сторонние Python-библиотеки не нужны.
D2 формируется как текст; SVG рисуется собственным кодом из того же графа,
а не компилятором D2. Установка D2 и Graphviz для запуска не требуется.
При желании сохранённый D2 можно отобразить отдельно установленным компилятором D2.

## Запуск

Откройте терминал в папке проекта. Для Windows:

```bat
python src\main.py --package A --repository examples\diamond.json --test-repo --ascii-tree
```

Для Linux/macOS:

```sh
python3 src/main.py --package A --repository examples/diamond.json --test-repo --ascii-tree
```

Допускается запуск через `run.bat` или `sh run.sh` с теми же аргументами.
Справка: `python src/main.py --help`.

После запуска открывается изображение, а в `output/` сохраняются `A.d2` и `A.svg`.
Файлы одного корневого пакета перезаписываются при повторном запуске.
Ребро направлено от пакета к его зависимости. Общие вершины не дублируются на изображении.

Пример D2 для ромба:

```d2
direction: down
n0: "A"
n1: "B"
n2: "C"
n3: "D"
n0 -> n1
n0 -> n2
n1 -> n3
n2 -> n3
```

Дополнительное дерево:

```text
A
|-- B
|   `-- D
`-- C
    `-- D [повтор]
```

Циклическое ребро не теряется в D2/SVG; в дереве повтор на активном пути отмечается `[цикл]`.
Уже раскрытая общая зависимость отмечается `[повтор]`, что предотвращает лишнее разворачивание.

## Параметры

- `--package`: обязательное имя корневого пакета.
- `--repository`: обязательный адрес JSON API или путь к тестовому JSON.
- `--test-repo`: локальный JSON с заглавными латинскими именами.
- `--filter`: исключить имена по подстроке без учёта регистра.
- `--ascii-tree`: дополнительно вывести дерево; без флага дерево не печатается.

Программа получает `<адрес>/<имя>/json`. Адрес `https://pypi.org` также поддерживается:
путь `/pypi` добавляется автоматически. HTML-индекс `/simple` не поддерживается.
Отладочная конфигурация этапа 1 и порядок загрузки этапа 4 здесь не выводятся.

## Различные тестовые графы

```sh
python src/main.py --package A --repository examples/single.json --test-repo
python src/main.py --package A --repository examples/chain.json --test-repo
python src/main.py --package A --repository examples/cycle.json --test-repo --ascii-tree
python src/main.py --package A --repository examples/self_cycle.json --test-repo --ascii-tree
python src/main.py --package A --repository examples/diamond.json --test-repo --filter B
```

Проверяются одиночная вершина, цепочка, ромб, циклы, петля и фильтрация.
Пакетные примеры: `scripts\demo.bat` или `sh scripts/demo.sh`.
Если исключён корень, сохраняется изображение пустого графа с пояснением.

## Три реальных пакета

Для получения актуальных метаданных из интернета выполните:

```sh
python src/main.py --package python-dateutil --repository https://pypi.org/pypi --ascii-tree
python src/main.py --package six --repository https://pypi.org/pypi --ascii-tree
python src/main.py --package pytz --repository https://pypi.org/pypi --ascii-tree
```

Команды собраны в `scripts\demo_real.bat` и `scripts/demo_real.sh`.
Для повторяемой демонстрации без внешнего интернета запустите в первом терминале:

```sh
python -m http.server 8000 --bind 127.0.0.1 --directory examples/pypi
```

Во втором терминале выполните:

```sh
python src/main.py --package python-dateutil --repository http://127.0.0.1:8000 --ascii-tree
python src/main.py --package six --repository http://127.0.0.1:8000 --ascii-tree
python src/main.py --package pytz --repository http://127.0.0.1:8000 --ascii-tree
```

Снимок: python-dateutil 2.9.0.post0 зависит от six; six 1.17.0 и pytz 2026.4 не имеют зависимостей.
Все три графа сформированы и проверены. Источник снимка — метаданные реальных установленных пакетов,
полученные `pip inspect`; подробности в `examples/metadata-origin.md` и `COMPARISON.md`.
Текущие версии публичного PyPI могут иметь другой состав зависимостей.

## Сравнение с менеджером пакетов

У pip нет встроенной команды рисования дерева или изображения графа.
В `COMPARISON.md` сопоставлены D2/SVG/ASCII с нативным JSON-выводом `pip inspect` для трёх пакетов.
Имена и рёбра снимка совпадают с установленными метаданными; объяснены отличия
между графом объявлений последней версии и решением pip для конкретного окружения.
Программа не вызывает pip для получения зависимостей.

## Ошибки и ограничения

Проверяются параметры, HTTP, JSON, имена пакетов, наличие целевых вершин,
ошибки файловой системы и невозможность открыть браузер.
При ошибке открытия SVG остаётся на диске: откройте его вручную.
Ответ HTTP ограничен 8 МиБ, время запроса — 15 секундами.
Слишком глубокий рекурсивный граф завершается понятным сообщением.

Программа извлекает имена из `requires_dist`, но не разрешает версии,
не вычисляет маркеры среды и extras. Она не устанавливает и не импортирует исследуемые пакеты.
Поэтому это визуализатор объявленных зависимостей, а не полноценный заменитель pip.
В среде проверки внешний доступ к PyPI недоступен: программа проверена через локальный HTTP
и снимки реальных метаданных. Нативный запуск на Windows в этой среде не проверялся.

## Проверка

```sh
python -m unittest discover -s tests -v
python tests/check_style.py
```

Автотесты не требуют интернета и не открывают окон: вызов браузера подменяется в тестах.
Проверяются также сохранение файлов, XML-экранирование, рёбра циклов, общие зависимости
и ошибки открытия изображения. Изображения отдельно проверены браузером Chromium.
Коды завершения: 0 — успех, 1 — ошибка данных/записи/браузера, 2 — ошибка параметров.

## Файлы

- `src/config.py`: параметры и их проверка.
- `src/repository.py`: стандартный HTTP-клиент, метаданные и кэш.
- `src/local_repository.py`: проверка тестового репозитория.
- `src/graph.py`: DFS, фильтрация и циклы.
- `src/d2_format.py`: текст D2 со стабильными идентификаторами.
- `src/svg_layout.py`: размещение вершин; BFS используется только для координат.
- `src/svg_format.py`: SVG, стрелки, петли, XML-экранирование.
- `src/ascii_tree.py`: дерево с отметками циклов и повторов.
- `src/visualization.py`: сохранение файлов и открытие изображения.
- `src/main.py`: запуск этапа 5.
- `examples/`, `tests/`, `scripts/`: данные, проверки и демонстрации.

Папка `output/` исключена из Git. Архивы, кэш, PDF и файлы IDE в репозиторий не добавляются.
