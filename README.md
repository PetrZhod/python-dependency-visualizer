# Этап 3. Транзитивный граф, DFS, фильтр и циклы

Консольная программа строит граф зависимостей собственным рекурсивным обходом в глубину (DFS).
Поддерживаются транзитивные зависимости, фильтрация пакетов, обработка циклов
и работа с локальным тестовым репозиторием. Результат выводится списком смежности.

## Требования

- Python 3.10 или новее.
- Сторонние Python-библиотеки не требуются.
- Для локальных примеров интернет не требуется. Для обращения к PyPI нужен интернет.

## Запуск тестового графа

Откройте PowerShell в корне проекта, где находятся `src` и `run.bat`, и выполните:

```powershell
python src/main.py --package A --repository examples/diamond.json --test-repo
```

Ожидаемый вывод:

```text
A -> B, C
B -> D
C -> D
D -> (нет)
```

Общая зависимость `D` посещается один раз. Независимые от корня компоненты не обходятся.

## Демонстрация цикла

```powershell
python src/main.py --package A --repository examples/cycle.json --test-repo
```

Программа выведет граф и сообщение `Цикл: A -> B -> C -> A`.
Ребро цикла сохраняется, бесконечного обхода нет.
Диагностика показывает обратные рёбра DFS, а не перечисляет все возможные циклы.

## Демонстрация фильтра

```powershell
python src/main.py --package A --repository examples/diamond.json --test-repo --filter B
```

Ожидаемый граф:

```text
A -> C
C -> D
D -> (нет)
```

Пакет `B` исключается. Пакет `D` остаётся достижимым через `C`.
Если к потомку ведёт только исключённая ветка, такой потомок не анализируется.
Подстрока проверяется в нормализованном имени без учёта регистра.
Исключение корневого пакета даёт пустой граф и диагностическое сообщение.

## Формат тестового репозитория

```json
{
  "A": ["B", "C"],
  "B": ["D"],
  "C": ["D"],
  "D": []
}
```

Ключ — имя пакета, список — его прямые зависимости. Имена состоят из заглавных латинских букв.
Каждый упомянутый пакет должен присутствовать как ключ, даже если его список пуст.
Повторяющиеся ключи, неверные типы, неизвестные цели и неправильные имена отклоняются.
Повторяющиеся рёбра удаляются.

В каталоге `examples` находятся примеры:

- `single.json` — пакет без зависимостей.
- `chain.json` — цепочка зависимостей.
- `diamond.json` — общая зависимость двух пакетов.
- `cycle.json` — цикл из трёх пакетов.
- `self_cycle.json` — зависимость пакета от самого себя.
- `disconnected.json` — несвязанные компоненты.
- `empty.json` — пустой репозиторий.
- `invalid.json` — ссылка на отсутствующий пакет.

Для демонстрации графов, фильтрации и ошибок запустите `scripts/demo.bat`.
Для демонстрации ошибок параметров запустите `scripts/errors.bat`.
Окна BAT-сценариев остаются открытыми до нажатия клавиши.
В Linux/macOS выполните `sh scripts/demo.sh` или `sh scripts/errors.sh`.

## Запуск с PyPI

```powershell
python src/main.py --package peppercorn --repository https://pypi.org/pypi
```

Метаданные последней версии каждого пакета загружаются через JSON API.
Большие графы требуют много последовательных запросов. Ответы кешируются на время запуска.
При превышении глубины рекурсии программа сообщает об ошибке без traceback.

Поле `info.requires_dist` анализируется без вызова менеджеров пакетов и сторонних библиотек.
Учитываются все объявления зависимостей, включая extras и условия окружения.
Маркеры окружения не вычисляются, ограничения версий не разрешаются.
Для каждого имени запрашиваются метаданные последней версии.
Поэтому граф объявленных зависимостей может отличаться от состава установки pip.

Для PyPI используйте `https://pypi.org/pypi`. Адрес `https://pypi.org` также принимается.
Simple API `/simple` не поддерживается. Другой репозиторий должен предоставлять совместимый JSON API.
Описание API: https://docs.pypi.org/api/json/.

## Параметры

| Опция | Назначение |
|---|---|
| `--package` | Обязательное имя корневого пакета |
| `--repository` | Обязательный URL JSON API или путь к тестовому JSON-файлу |
| `--test-repo` | Выбор локального тестового репозитория |
| `--ascii-tree` | Параметр конфигурации; ASCII-дерево в этой версии не строится |
| `--filter` | Подстрока исключаемых пакетов; по умолчанию пустая |

Флаги передаются без значений. Пути с пробелами заключайте в двойные кавычки.
Вывод этой версии — список смежности и сообщения о циклах.
Порядок установки, D2 и изображение графа не формируются.

## Обработка ошибок

Ошибки HTTP, DNS, тайм-ауты, некорректные метаданные и неверные тестовые файлы
сопровождаются сообщением без traceback. Размер HTTP-ответа ограничен 8 МиБ,
тайм-аут запроса — 15 секунд.

Коды завершения:

- `0` — успешный запуск или вывод справки.
- `1` — ошибка получения, обработки данных или превышение глубины рекурсии.
- `2` — ошибка параметров командной строки.

```powershell

python tests/check_style.py
```

В Windows также можно использовать `.\run.bat` с теми же параметрами.
В Linux/macOS используйте `python3` вместо `python` или `sh run.sh` с параметрами.

## Структура проекта

- `src/config.py` — параметры командной строки и их проверка.
- `src/repository.py` — получение метаданных из JSON API.
- `src/local_repository.py` — чтение и проверка тестового репозитория.
- `src/graph.py` — рекурсивный DFS, фильтрация, циклы и вывод графа.
- `src/main.py` — точка входа и обработка ошибок.
- `tests` — автотесты и проверка оформления.
- `examples` — тестовые графы.
- `scripts` — сценарии демонстрации запуска и ошибок.
- `run.bat`, `run.sh` — запуск программы с переданными параметрами.
