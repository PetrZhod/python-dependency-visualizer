# Этап 4. Порядок загрузки зависимостей

Программа строит граф рекурсивным DFS и выводит порядок, в котором каждая
зависимость предшествует использующему её пакету. Установка пакетов не выполняется.
Используются только стандартные библиотеки Python 3.10 или новее.

## Запуск

Откройте терминал в папке проекта. Для Windows:

```bat
python src\main.py --package A --repository examples\diamond.json --test-repo
```

Для Linux/macOS:

```sh
python3 src/main.py --package A --repository examples/diamond.json --test-repo
```

Ожидаемый результат:

```text
Порядок загрузки: D -> B -> C -> A
```

Допускается запуск через `run.bat` или `sh run.sh` с теми же аргументами.
Справка: `python src/main.py --help`.

## Параметры

- `--package`: обязательное имя корневого пакета.
- `--repository`: обязательный адрес JSON API репозитория или путь к тестовому JSON.
- `--test-repo`: читать локальный JSON с именами из заглавных латинских букв.
- `--filter`: исключить имена с указанной подстрокой без учёта регистра.
- `--ascii-tree`: принимается для совместимости; дерево предусмотрено только этапом 5.

Для публичного репозитория:

```sh
python src/main.py --package six --repository https://pypi.org/pypi
```

Поддерживается JSON API вида `<адрес>/<имя>/json`, а не HTML-страницы `/simple`.
В URL `https://pypi.org` путь `/pypi` добавляется автоматически.
Программа читает объявления `requires_dist` последней версии и извлекает имена;
не выбирает версии и не вычисляет условия окружения или дополнительные группы extras.
Поэтому граф объявленных зависимостей может отличаться от результата pip.
Сетевой запрос ограничен 15 секундами и 8 МиБ ответа; ошибки выводятся без трассировки.

## Различные случаи

```sh
python src/main.py --package A --repository examples/single.json --test-repo
python src/main.py --package A --repository examples/chain.json --test-repo
python src/main.py --package A --repository examples/diamond.json --test-repo --filter B
python src/main.py --package A --repository examples/cycle.json --test-repo
python src/main.py --package A --repository examples/self_cycle.json --test-repo
python src/main.py --package A --repository examples/disconnected.json --test-repo
```

Результаты: одиночный `A`; цепочка `C -> B -> A`; ромб с фильтром `D -> C -> A`;
для циклов — сообщение об отсутствии порядка и код 1; несвязанная компонента не обходится.
Общая зависимость выводится один раз. Порядок независимых ветвей детерминирован сортировкой.
При исключении корня выводится объяснение; недостижимые зависимости не загружаются.

Пакетные примеры: `scripts\demo.bat` или `sh scripts/demo.sh`.
Публичные примеры трёх пакетов: `scripts\demo_real.bat` или `sh scripts/demo_real.sh`.

## Повторяемая демонстрация HTTP

В первом терминале из папки проекта выполните:

```sh
python -m http.server 8000 --bind 127.0.0.1 --directory examples/pypi
```

Во втором терминале выполните:

```sh
python src/main.py --package python-dateutil --repository http://127.0.0.1:8000
```

Результат снимка: `six -> python-dateutil`. Происхождение и версии метаданных
описаны в `examples/metadata-origin.md`. Это локальная демонстрация реальных метаданных,
а не заявление о выполненном запросе к публичному PyPI.

## Сравнение с pip

См. `COMPARISON.md`: сравнение выполнено настоящим pip 24.2 на изолированных
локальных wheel-пакетах. Цепочка совпала; у ромба различается допустимый порядок
независимых ветвей. В отличие от программы, pip может устанавливать циклический набор.

## Проверка

```sh
python -m unittest discover -s tests -v
python tests/check_style.py
```

Автотесты не требуют интернета. Проверяются параметры, HTTP и ошибки метаданных,
DFS, циклы, фильтрация, общие зависимости и порядок загрузки.
Код завершения: 0 — успех, 1 — ошибка данных или графа, 2 — ошибка параметров.

## Файлы

- `src/config.py`: разбор и проверка параметров.
- `src/repository.py`: получение JSON стандартным `urllib`, разбор имён и кэш.
- `src/local_repository.py`: тестовый репозиторий и проверка его структуры.
- `src/graph.py`: рекурсивный DFS, фильтрация и обнаружение циклов.
- `src/order.py`: зависимости раньше использующих их вершин.
- `src/main.py`: запуск и сообщения об ошибках.
- `examples/`: различные тестовые графы и снимок метаданных.
- `tests/`: автоматические проверки и проверка измеримых ограничений.
- `scripts/`: демонстрации и некорректные параметры.

Вывод порядка предусмотрен только этим этапом. Графические представления относятся к этапу 5.
