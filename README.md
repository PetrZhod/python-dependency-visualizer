# Этап 3. Транзитивный граф, DFS, фильтр и циклы

Граф строится собственным рекурсивным DFS. Каждая достижимая вершина посещается один раз.
Добавлены исключение пакетов по подстроке, обработка циклов и локальный тестовый режим.
Результат выводится списком смежности. D2 и ASCII-дерево относятся к этапу 5.

## Запуск без интернета

```powershell
python src/main.py --package A --repository examples/diamond.json --test-repo
```

Ожидаемый результат:

```text
A -> B, C
B -> D
C -> D
D -> (нет)
```

Цикл:

```powershell
python src/main.py --package A --repository examples/cycle.json --test-repo
```

Программа завершится нормально и покажет путь A -> B -> C -> A.
Ребро цикла сохраняется в графе, бесконечного обхода нет.
Диагностика показывает обратные рёбра DFS, а не перечисляет все возможные циклы.

Фильтр:

```powershell
python src/main.py --package A --repository examples/diamond.json --test-repo --filter B
```

Пакет B исключается, D остаётся достижимым через C.
Если к потомку вела только исключённая ветка, такой потомок не анализируется.
Подстрока проверяется в имени после нормализации без учёта регистра.
Исключённый корень даёт пустой граф и понятное сообщение.

## Формат тестового репозитория

```json
{
  "A": ["B", "C"],
  "B": ["D"],
  "C": ["D"],
  "D": []
}
```

Ключ — пакет, список — его прямые зависимости. Допустимы заглавные латинские буквы.
Каждый упомянутый пакет должен присутствовать как ключ, даже если его список пуст.
Повторяющиеся ключи, неверные типы, неизвестные цели и неправильные имена отклоняются.
Повторяющиеся рёбра удаляются. Независимые от корня компоненты не обходятся.

Примеры: single, chain, diamond, cycle, self_cycle, disconnected, empty, invalid.
Сценарии scripts/demo.bat и scripts/demo.sh показывают разные графы, фильтр и ошибку.
В Windows BAT содержит pause, поэтому результаты не исчезают.

## Реальный репозиторий

```powershell
python src/main.py --package peppercorn --repository https://pypi.org/pypi
```

Нужен интернет. Большие графы требуют много последовательных запросов.
Общие зависимости кешируются на время запуска. При превышении глубины рекурсии
программа сообщает об ошибке, а не выводит traceback.
--ascii-tree пока только резервирует режим для этапа визуализации.
Порядок установки, D2 и изображение графа на этом этапе не реализованы.

## Какие именно зависимости анализируются

Программа читает метаданные последней версии пакета по адресу
`<база JSON API>/<имя>/json`. Для PyPI база — https://pypi.org/pypi.
Короткий адрес https://pypi.org тоже принимается. Simple API /simple не поддерживается.
Другой репозиторий должен предоставлять совместимый JSON API с объектом info.

Поле info.requires_dist содержит декларации Requires-Dist.
Анализируются все объявленные зависимости, включая extras и условия окружения.
Маркеры не вычисляются: это граф деклараций, а не план установки для текущей ОС.
Ограничения версий не разрешаются. Для каждого имени запрашивается последняя версия.
Поэтому результат может отличаться от графа пакетов, реально установленных pip.

Для получения зависимостей используются только urllib, json и собственный код.
Менеджеры пакетов, pipdeptree, packaging и другие сторонние библиотеки не вызываются.
Описание API: https://docs.pypi.org/api/json/.

Ошибки HTTP, DNS, тайм-ауты, чужое имя пакета, неверный JSON и неверный requires_dist
сообщаются без traceback с кодом 1. Ответ ограничен 8 МиБ, тайм-аут — 15 секунд.

## Требования и запуск

Нужен Python 3.10 или новее. Сторонние Python-библиотеки не нужны.
Это консольное приложение, не графическое окно и не эмулятор оболочки.

Открой PowerShell в корне проекта, где находятся src и run.bat.
Справка:

```powershell
python src/main.py --help
```

Проверки:

```powershell
python -m unittest discover -s tests -v
python tests/check_style.py
```

В Linux/macOS используй python3 вместо python либо ./run.sh с параметрами.
В Windows можно использовать .\run.bat с теми же параметрами.

## Параметры

| Опция | Назначение |
|---|---|
| `--package` | Обязательное имя пакета |
| `--repository` | Обязательный URL JSON API или путь к тестовому файлу |
| `--test-repo` | Флаг выбора тестового репозитория |
| `--ascii-tree` | Флаг выбора ASCII-дерева для будущего этапа 5 |
| `--filter` | Подстрока исключаемых пакетов; по умолчанию пустая |

Флаги передаются без значений: --ascii-tree, а не --ascii-tree=true.
Пути с пробелами заключай в двойные кавычки.
Ошибки параметров завершают программу с кодом 2; --help возвращает 0.

## Структура

- src — исходный код.
- tests — автотесты и проверка измеримых ограничений оформления.
- examples — тестовые данные.
- scripts — демонстрации для Windows и Linux/macOS.
- run.bat и run.sh — запуск с переданными пользователем параметрами.

Автоматическая проверка оформления не заменяет официальную проверку преподавателя.
