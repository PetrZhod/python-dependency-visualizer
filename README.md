# Этап 2. Получение прямых зависимостей

Консольная программа загружает прямые зависимости Python-пакета из JSON API репозитория.
При запуске выводятся объявления зависимостей, включая ограничения версий и маркеры окружения.
Конфигурация и транзитивный граф не выводятся.

## Требования

- Python 3.10 или новее.
- Доступ к интернету для обращения к PyPI.
- Сторонние Python-библиотеки не требуются.

## Запуск

Откройте PowerShell в корне проекта, где находятся `src` и `run.bat`, и выполните:

```powershell
python src/main.py --package requests --repository https://pypi.org/pypi
```

Программа выведет все объявления прямых зависимостей пакета `requests`.
Состав ответа зависит от текущих метаданных пакета на сервере.
Если пакет не объявляет зависимостей, программа выведет отдельное сообщение.

Другие примеры:

```powershell
python src/main.py --package six --repository https://pypi.org/pypi
python src/main.py --package peppercorn --repository https://pypi.org/pypi
```

Для последовательного запуска трёх примеров выполните `scripts/demo.bat`.
Для демонстрации ошибок параметров выполните `scripts/errors.bat`.
В Linux/macOS используйте `sh scripts/demo.sh` или `sh scripts/errors.sh`.

## Параметры

| Опция | Назначение |
|---|---|
| `--package` | Обязательное имя пакета |
| `--repository` | Обязательный URL JSON API репозитория |
| `--test-repo` | Выбор тестового режима; чтение тестового графа в этой версии не поддерживается |
| `--ascii-tree` | Параметр конфигурации; ASCII-дерево в этой версии не строится |
| `--filter` | Параметр конфигурации; фильтрация в этой версии не применяется |

При `--test-repo` программа выводит диагностическое сообщение и завершается с кодом 1.
Флаги передаются без значений. Пути с пробелами заключайте в двойные кавычки.

## Источник и обработка данных

Метаданные последней версии пакета загружаются по адресу `<база JSON API>/<имя>/json`.
Для PyPI используйте `https://pypi.org/pypi`. Адрес `https://pypi.org` также принимается.
Simple API `/simple` не поддерживается. Другой репозиторий должен предоставлять
совместимый JSON API с объектом `info` и полем `requires_dist`.

Программа читает все объявления `Requires-Dist`, включая extras и условия окружения.
Маркеры окружения не вычисляются, ограничения версий не разрешаются.
Результат описывает объявленные зависимости, а не состав установки для текущей ОС.
Поэтому он может отличаться от списка пакетов, устанавливаемых pip.

Для получения данных используются `urllib`, `json` и собственный код.
Менеджеры пакетов, `pipdeptree`, `packaging` и другие сторонние библиотеки не вызываются.
Описание JSON API: https://docs.pypi.org/api/json/.

## Обработка ошибок

Ошибки HTTP, DNS, тайм-ауты, некорректный JSON, несовпадение имени пакета
и неверная структура `requires_dist` сопровождаются сообщением без traceback.
Размер ответа ограничен 8 МиБ, тайм-аут запроса — 15 секунд.

Коды завершения:

- `0` — успешный запуск или вывод справки.
- `1` — ошибка получения или обработки данных.
- `2` — ошибка параметров командной строки.

## Справка и проверки

```powershell
python src/main.py --help
python -m unittest discover -s tests -v
python tests/check_style.py
```

В Windows также можно использовать `.\run.bat` с теми же параметрами.
В Linux/macOS используйте `python3` вместо `python` или `sh run.sh` с параметрами.

## Структура проекта

- `src` — обработка параметров, получение метаданных и точка входа.
- `tests` — автотесты и проверка оформления.
- `examples` — тестовые данные.
- `scripts` — сценарии демонстрации запуска и ошибок.
- `run.bat`, `run.sh` — запуск программы с переданными параметрами.
