# Сравнение с нативным выводом pip

## Исходные три реальных пакета

12 ноября 2026 года выполнена настоящая команда `python -m pip inspect`
для окружения Python 3.13.14 с pip 24.2. Использованы необходимые поля трёх пакетов:

| Пакет | Версия | Объявленные зависимости |
|---|---|---|
| python-dateutil | 2.9.0.post0 | six >=1.5 |
| six | 1.17.0 | нет |
| pytz | 2026.4 | нет |

Снимки прочитаны программой через настоящий локальный HTTP-сервер, без `--test-repo`.
Для первого корня получены две вершины и одно ребро; для двух других — по одной вершине.
Имена, версии и рёбра совпадают с метаданными тех же версий в выводе pip.
Ограничение `>=1.5` не изображается: граф показывает связи между именами.

После дополнения от 13 ноября реальные вершины подписаны, например,
`python-dateutil (2.9.0.post0)` и `six (1.17.0)`.
Версии извлекаются из того же ответа API, а не из локальной установки.
Подписи добавлены только на этапе 5; у тестовых букв версии отсутствуют.

## Почему нет изображения самого pip

У pip нет встроенной команды рисования графа или ASCII-дерева.
`pip inspect` возвращает JSON, а `pip show` — сведения с прямыми зависимостями.
Поэтому сравниваются наборы связей в разных представлениях, а не две графические команды.
Сторонние библиотеки получения зависимостей, включая pipdeptree, не используются.

Для отдельной проверки установленных пакетов:

```sh
python -m pip inspect > installed.json
python -m pip show python-dateutil six pytz
```

Программа сама pip не вызывает. Для визуализации исследуемые пакеты устанавливать не нужно.

## Дополнительный пример Jinja2

Снимок Jinja2 3.1.6 объявляет MarkupSafe 3.0.3 и Babel для группы `i18n`.
Зафиксированная Babel 2.9.1 объявляет pytz; снимок pytz имеет версию 2026.4.
Получены четыре вершины, три ребра и подписи с версиями в D2, SVG и ASCII.
Babel не объявляется обязательной зависимостью обычной установки Jinja2 без extras.

Jinja2 и MarkupSafe взяты из того же сохранённого pip inspect. Babel 2.9.1 взята
из публичного API конкретной версии: её установка в окружении не утверждается.
Источник и версии приведены в `examples/metadata-origin.md`.

## Причины различий и границы проверки

Программа читает объявления последней версии из указанного API, а pip inspect — установленную.
Она не разрешает ограничения версий, не вычисляет маркеры ОС/Python и extras.
Последние публичные версии могут давать другой, более крупный граф, чем фиксированный снимок.
Фильтрация исключает вершины; дерево отмечает циклы и повторные общие зависимости.

После изменения пройдены 72 автоматических теста; изображения отдельно отрисованы Chromium.
Для создания SVG используется собственный код, не внешний D2-компилятор.
Внешний DNS среды недоступен: живой запуск программы с публичным PyPI здесь не проверен.
Выполнены реальные локальные HTTP-запросы со снимками реальных метаданных.
Работа стандартного браузера Windows здесь не проверялась.
