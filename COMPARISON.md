# Сравнение порядка с pip

Проверка выполнена 12 ноября 2026 года: Python 3.13.14, pip 24.2.
Использован настоящий `python -m pip install`, а не имитация менеджера.
Для каждого графа создан независимый набор минимальных wheel-пакетов A–D версии 1.0
с `Requires-Dist`, соответствующими JSON. Это синтетические тестовые пакеты,
а не скачанные приложения. Каждый запуск устанавливал файлы только во временную папку.
Архивы и установленные файлы удалены после проверки и не включены в репозиторий.

Команда сравнения:

```sh
python -m pip install --no-index --find-links WHEELS --target TARGET --ignore-installed --no-compile A==1.0
```

Порядок pip взят из строки `Installing collected packages`, не из отчёта `--dry-run`.

| Граф | Программа | pip 24.2 |
|---|---|---|
| Одиночный | A | A |
| Цепочка | C, B, A | C, B, A |
| Ромб | D, B, C, A | D, C, B, A |
| Цикл A–B–C–A | Нет порядка, указан цикл | C, B, A |
| Петля A–А | Нет порядка, указан цикл | A |

Во всех пяти проверках pip завершился с кодом 0.
Для ромба оба порядка корректны: D расположен раньше B и C, а A позже обеих ветвей.
Зависимости между B и C нет; программа выбирает ветви по алфавиту, pip не обещает такой же порядок.
При цикле строгий топологический порядок невозможен. Программа сообщает об этом,
тогда как pip применяет собственную политику обработки циклов и всё же выполняет установку.

Программа ничего не устанавливает. Её порядок относится только к достижимому графу
после фильтрации. Исключение B в ромбе оставляет D, C, A; исключение корня даёт пустой граф.

## Отличия на публичных репозиториях

Программа читает объявления `requires_dist` последней версии пакета, выделяя имена.
Не решается задача совместимости версий, не вычисляются маркеры окружения и extras.
Pip выбирает версии под конкретные Python, платформу и параметры установки;
поэтому состав графа тоже может отличаться. В частности, установленный python-dateutil
2.9.0.post0 объявляет six, а полученные публичные метаданные версии 4.0.0 объявляли tzdata.
Нельзя сравнивать эти разные версии как будто они описывают один и тот же граф.

Справка о гарантии порядка pip:
https://pip.pypa.io/en/stable/cli/pip_install/#installation-order

Живой запрос из самой программы к внешнему PyPI в проверочной среде не выполнялся:
внешнее разрешение DNS недоступно. HTTP-клиент проверен через локальный сервер.
